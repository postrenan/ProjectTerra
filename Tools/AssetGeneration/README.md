# Asset Generation

Scripts Python (Blender/PBR) que geram os modelos e texturas do projeto, mais os
arquivos `.blend` de origem que eles produzem.

Os modelos realmente usados pelo jogo ficam importados em
`Assets/_Project/Models/`. Os `.blend` aqui são as fontes de geração — foram
movidos da raiz do repositório para manter a raiz limpa.

> Arquivos de backup do Blender (`.blend1`) são ignorados pelo git (ver `.gitignore`).
